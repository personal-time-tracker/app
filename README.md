# TimeTracer

Приложение для трекинга времени с интеграцией календаря и Shortcuts.

## Возможности

### 🕐 Трекинг времени
- Виджет на главном экране показывает текущее занятие
- Автоматическое создание событий в календаре
- Завершение предыдущего занятия при начале нового

### ⚡ Интеграция с Shortcuts
- Быстрый старт трекинга через Shortcuts
- Выбор календаря из списка
- Ввод названия занятия
- Автоматическое завершение сессий

### 📊 Аналитика
- Подробная статистика по периодам (день/неделя/месяц)
- Графики активности по дням
- Топ занятий по времени
- Анализ по категориям календарей

## Настройка

### 1. Разрешения
Приложение запросит доступ к календарю при первом запуске.

### 2. Shortcuts интеграция
1. Открой приложение Shortcuts
2. Создайте новый шорткат
3. Добавьте действие "Начать трекинг времени"
4. Выберите календарь и введите название занятия
5. Добавьте действие "Завершить трекинг времени"

### 3. Виджет на главном экране
- Нажмите на виджет в приложении
- Выберите календарь
- Введите название занятия
- Нажмите "Начать занятие"

## Архитектура

### Модели
- `TimeSession` - модель сессии времени
- `CalendarInfo` - информация о календаре

### Сервисы
- `CalendarService` - работа с календарем через EventKit
- `ShortcutsService` - интеграция с Shortcuts

### Представления
- `CurrentActivityWidget` - виджет текущего занятия
- `ActivitySelectionView` - выбор занятия и календаря
- `AnalyticsView` - экран аналитики

## Установка

1. Клонируйте репозиторий
2. Откройте проект в Xcode
3. Выберите устройство или симулятор
4. Нажмите Run (⌘+R)

## Использование

### Основной поток
1. Откройте приложение
2. Нажмите "Начать занятие" на виджете
3. Выберите календарь
4. Введите название занятия
5. Приложение автоматически создаст событие в календаре

### Shortcuts
1. Создайте шорткат с действием "Начать трекинг времени"
2. Добавьте параметры: название занятия и календарь
3. Запустите шорткат для быстрого старта трекинга

### Аналитика
1. Перейдите на вкладку "Аналитика"
2. Выберите период (день/неделя/месяц)
3. Просматривайте статистику и графики

## Разработка

### Добавление новых функций
1. Создайте модель в папке `Models/`
2. Добавьте сервис в папку `Services/`
3. Создайте представление в папке `Views/`
4. Обновите `ContentView.swift` при необходимости

### Тестирование
- Протестируйте на реальном устройстве для проверки календарной интеграции
- Проверьте работу Shortcuts в приложении Shortcuts
- Убедитесь в корректности аналитики
